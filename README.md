# Gaming Website - React + Django

A gaming website built with React frontend and Django backend. The frontend uses React and Vite for smooth animations with GSAP library, making the website responsive and aesthetic.

## Features
- React frontend with Vite build system
- Django backend for serving the frontend and API endpoints
- GSAP animations for smooth user experience
- Responsive design with Tailwind CSS

## Setup Instructions

### Frontend (React + Vite)
1. Install Node.js dependencies:
   ```bash
   npm install
   ```

2. Build the React application:
   ```bash
   npm run build
   ```

3. For development, run:
   ```bash
   npm run dev
   ```

### Backend (Django)
1. Install Python dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Run Django migrations:
   ```bash
   python manage.py migrate
   ```

3. Start the Django development server:
   ```bash
   python manage.py runserver
   ```

## Project Structure
- `src/` - React frontend source code
- `backend/` - Django backend configuration
- `frontend/` - Django app for serving React frontend
- `dist/` - Built React application (generated by Vite)
- `public/` - Static assets

## Development Workflow
1. Make changes to React components in `src/`
2. Build the frontend with `npm run build`
3. Django will serve the updated build automatically
